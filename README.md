
# ORION — Budget Management System 💰

A command-line budget management application built using C and Python.

## 📌 Overview

ORION helps users manage their personal finances by tracking income, recording expenses, and providing budget recommendations.

## ✨ Features

- User registration and login
- Income and expense tracking
- Expense categorization
- Category prioritization using selection sort
- Rule-based budget recommendations
- File-based data storage

## 🛠️ Technologies

- C — Core application logic
- Python — Budget recommendations
- Shell Script — Compilation and execution
- File I/O — Data persistence

## 🚀 Getting Started

### Requirements

- GCC or Clang
- Python 3
- macOS or Linux terminal

### Run the Application

Clone the repository:

```bash
git clone https://github.com/dikshyalaudari/ORION-Budget-Manager.git
cd ORION-Budget-Manager
```

Run:

```bash
bash run_orion.sh
```

## ⚠️ Limitations

This is an academic project intended for learning and demonstration. Account passwords are stored in plain text, so do not use real passwords or sensitive financial information.
